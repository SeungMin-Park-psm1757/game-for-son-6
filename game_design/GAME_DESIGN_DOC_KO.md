# GoalPop Arena Web
## 코덱스용 게임 기획서

## 1. 프로젝트 개요

**작업명:** GoalPop Arena Web  
**장르:** 캐주얼 1:1 아케이드 축구  
**플랫폼:** 모바일 웹 우선, 데스크톱 웹 지원  
**1회 플레이 시간:** 1~3분  
**핵심 판타지:** 큰 머리의 과장된 캐릭터로 점프하고 차고 스페셜을 써서 우스꽝스럽고 통쾌한 골을 넣는 게임

이 프로젝트는 다음 요소를 중심으로 설계합니다.

- 즉시 이해되는 조작
- 짧고 반복 가능한 경기
- 기억에 남는 캐릭터
- 화끈한 골 연출
- 모바일에서도 잘 보이는 UI
- 가볍게 배포 가능한 웹앱 구조

중요한 원칙은 **“장르 감성은 참고하되 결과물은 오리지널”**입니다.

복제하면 안 되는 것:
- 실존 선수 닮은꼴
- 기존 게임 캐릭터 도안
- 특정 타이틀의 UI 배치 그대로
- 기존 로고 / 제목 / 브랜딩

## 8. 경기 규칙

### 기본 형식
- 1:1 횡스크롤 축구
- 기본 경기 시간 45초
- 종료 시 골이 많은 쪽 승리

### 동점 처리
추천 순서:
1. 15초 연장전
2. 그래도 동점이면 선취골 서든데스

### 득점 처리
- 공이 골라인을 완전히 넘으면 득점
- 득점 후:
  - 짧은 정지 연출
  - 골 VFX / SFX
  - 스코어 갱신
  - 중앙 재배치
  - 1초 카운트다운 후 재개

### 보상
- 승리: 더 많은 코인
- 패배: 소량 코인
- 캐릭터별 첫 승리 보너스

## 9. 핵심 게임 시스템

## 9.1 이동
- 좌우 이동
- 짧고 경쾌한 점프
- 착지 후 회복은 짧게
- 현실적인 관성보다 아케이드 조작감 우선

## 9.2 킥
- 전방 짧은 범위 킥
- 짧은 활성 히트박스
- 공과 맞는 타이밍이 좋으면 더 강한 임펄스
- 공중 킥 허용

## 9.3 스페셜
각 캐릭터는 1개의 시그니처 스페셜을 가집니다.

조건:
- 한눈에 알아볼 수 있어야 함
- 강하지만 경기를 망치면 안 됨
- 쿨다운 또는 게이지로 제어

### 예시 스페셜
- Fire Shot: 강한 화염 슛
- Wall Block: 전방 방어막
- Dash Kick: 짧은 돌진 후 강킥
- Magnet Curve: 공 궤도 살짝 굴절

## 9.4 공
- 원형 물리 바디
- 강한 탄성
- 읽기 쉬운 포물선
- 최대 속도 제한
- 과도한 난반사는 감쇠

상태 예시:
- flaming
- frozen
- heavy
- shielded

## 9.5 골 후 재시작
- 짧은 축하 연출
- 기본 위치 재배치
- 중앙 공 리스폰
- 1초 준비 후 재개

## 10. 난이도 / CPU 설계

### MVP 난이도
- Easy
- Normal
- Hard

### CPU 방식
FSM 기반으로 설계합니다.

상태:
- 기본 위치 유지
- 공 추적
- 수비 복귀

### 설계 목표
- Easy는 일부 기회를 놓친다
- Normal은 충분히 경쟁적이다
- Hard는 똑똑하지만 노골적으로 치트처럼 보이면 안 된다

### 안티 스트레스 규칙
- 숨겨진 속도 치트 금지
- 쿨다운 공유
- 반응 지연 일부 허용
- 완벽 차단 반복 금지

## 11. 캐릭터 방향

캐릭터는 아래 성격을 가져야 합니다.

- 오리지널
- 과장된 비율
- 한눈에 구분 가능
- 작은 화면에서도 읽힘

### 비율
- 큰 머리
- 작은 몸통
- 짧은 팔다리
- 큰 신발 / 장갑 가능
- 강한 실루엣

### MVP 캐릭터 예시
1. **Blaze** — 스트라이커형, 화염 슛
2. **Bolt** — 스피드형, 돌진 킥
3. **Atlas** — 수비형, 방어벽
4. **Ripple** — 트릭형, 궤도 굴절

모든 캐릭터는 실존 선수와 닮지 않도록 합니다.

3. 밸런스 값은 config로 분리한다
4. 모바일 터치 조작을 초기에 검증한다
5. 오리지널 아트 방향을 강한 제약으로 둔다
6. 첫 완주 루프 전에는 기능 욕심을 줄인다

## 25. 최종 한 줄 정의

모바일과 데스크톱 브라우저에서 가볍게 즐길 수 있는,  
**큰 머리의 오리지널 캐릭터가 점프·킥·스페셜로 난장판 같은 골을 만들어내는 1:1 아케이드 축구 웹앱**을 만든다.
